What happens next

  1. The form opens a pre-filled suggestion on GitHub. Submitting requires a free GitHub account.
  2. The maintainer checks the source and adds the information to the data.
  3. The analysis is rerun and the change appears in the map, search and report.

Without a GitHub account: copy the suggestion as text and send it to the maintainer. The form fields are in Finnish because the maintainer works in Finnish; you can write in English.
